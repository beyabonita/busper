Component Blueprint & State Specifications

Breakdown of core reusable UI modules, their functional anatomy, and interactive micro-states.

1. Hero Card Component
Anatomy
  • Outer Ring: 160px circular gradient border (Indigo-Purple).
  • Badge: Graduation cap icon with tooltip indication.
  • Live Status Pill: Pulsing green indicator showing internship availability.
  • CTA Pair: Primary button (Projects) + Secondary outline (Security Lab).
Interaction States
Hover on Avatar → Camera overlay icon fades in (`opacity: 1`) enabling custom photo upload modal.
2. Phishing Security Lab Component
Anatomy
  • Scenario Stepper: 3 realistic student/academic phishing samples.
  • Header Inspector: Collapsible SPF/DKIM validation summary.
  • Action Decision Buttons: [Flag Phishing] vs [Mark Safe].
  • Telemetry Feedback: Explanatory banner showing exact red flags.
Interaction States
On click → Triggers synthesized Web Audio beep/chime, updates score pill, and reveals threat breakdown.
3. Printable Resume Sheet Mode
Anatomy
  • Paper Aspect: Standard A4 ratio (1:1.414) in crisp white presentation.
  • Header Banner: Synchronized photo, name, and clear contact links.
  • Two-Column Layout: Left (Education & Core Skills) + Right (Experience & Projects).
  • Print Styling: Optimized `@media print` removing background blurs and buttons.
4. Theme & Accent Switcher
Anatomy
  • Theme Controller: Dark mode (default), Light mode, Cyberpunk mode.
  • Accent Controller: Indigo, Rose, Emerald, Amber, Cyan.
  • Persistence: Saved directly in browser `localStorage`.

How to Use & Submit with Wireframing Tools

Instructions to import, view, edit, or present this Hi-Fi framework using Draw.io, Figma, or Canva.

Option 1: Draw.io (Instant)

Draw.io is 100% free, runs instantly in your web browser, and requires no account.

  1. Download File:
    Click hifi-portfolio-framework.drawio.
  2. Open in Browser:
    Go to app.diagrams.net.
  3. Import:
    Click "Open Existing Diagram" and select the downloaded .drawio file.
  4. Export for Submission:
    Click File → Export As → PDF or PNG.
Option 2: Figma

For interactive component prototypes, auto-layouts, and design handoffs.

  1. Create Canvas:
    Open Figma and create a Frame at 1440 × 2500 px (Desktop).
  2. Apply Tokens:
    Set background to #0B0D14 and fonts to Outfit + Plus Jakarta Sans.
  3. Assemble Sections:
    Build Hero (Avatar with 160px circle), Security Lab card, 3 Projects, and Footer.
  4. Share Link:
    Click Share → Copy Link to submit your Figma prototype.
Option 3: Canva

Ideal for presentation slides, visual wireframe posters, and project report attachments.

  1. Create Design:
    Choose Website (1366 × 768) or Infographic (800 × 2000).
  2. Upload Elements:
    Upload your profile image and place cards with dark backgrounds (#151926).
  3. Add Sections:
    Add wireframe blocks for Navigation, Bio, Security Simulator, and Skills.
  4. Download:
    Click Share → Download → PDF Standard / PNG.
